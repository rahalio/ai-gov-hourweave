# Hourweave — User stories

**Product:** [PRODUCT.md](./PRODUCT.md)


### Workforce planner / CHCO analyst

- As a workforce planner, I want to import a job-family task inventory with time shares, so that I know which activities are candidates before vendors pitch tools.
- As a workforce planner, I want to simulate hour banks under Relieve vs Replace for the same job family, so that leadership sees the labour-relations difference before approving budget.

### Process owner

- As a process owner, I want to score a process on Viable / Valuable / Vital, so that we stop funding low-viability demos.
- As a process owner, I want to assign freed hours to specific backlog queues, so that automation visibly shortens citizen wait times.

### Frontline supervisor

- As a supervisor, I want Augment suggestions to show evidence and confidence to my team, so that staff remain accountable decision-makers.
- As a supervisor, I want to flag Split-up residue that is burning out specialists, so that we redesign rather than normalise linguistic or clerical janitorial work.

### Finance / performance

- As a finance analyst, I want hour-bank statements that separate cost take-out from value redeployment, so that savings claims match CHCO reality.
- As a performance lead, I want pre/post quality and handling-time metrics on each wave, so that we evidence the speed-quality-cost claim.

### Governance / labour / IG

- As a labour relations officer, I want Replace proposals blocked until impact assessment and consultation are complete, so that we do not violate agreements.
- As an inspector general analyst, I want an immutable log of mode choices and rollbacks, so that automation governance is auditable.
- As a process owner (exception), I want to roll back a live bot when error rates spike, so that bad automation does not silently continue.
